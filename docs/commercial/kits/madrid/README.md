## Contexto Madrid (resumen)

| Actor | Rol |
|-------|-----|
| **SERMAS** | Servicio de salud de la Comunidad de Madrid |
| **Escuela Madrileña de Salud** | Educación para la salud y enfermedades crónicas ([web](https://www.comunidad.madrid/salud/escuela-madrilena-salud)) |
| **Asociación Diabetes Madrid (ADM)** | Educación, talleres, Escuela Diabetes Madrid ([web](https://diabetesmadrid.org/)) |
| **Madrid Salud** | Programas de prevención y promoción |
| **Consejería de Digitalización** | Salud digital (p. ej. telemonitorización IoMT) |

**Posicionamiento clave:** Migajas es **capa educativa** de conteo de carbohidratos. **No compite** con la plataforma de telemonitorización ni con la Tarjeta Sanitaria Virtual.

## Piloto sugerido (Madrid)

| Parámetro | Propuesta |
|-----------|-----------|
| **Ámbito** | 2–3 centros de atención primaria de una misma gerencia (p. ej. Madrid capital o metropolitana norte) |
| **Duración** | 6 meses |
| **Usuarios objetivo** | 200–500 |
| **Referente** | Educación diabetológica AP + Escuela Madrileña de Salud |
| **Aliado opcional** | Asociación Diabetes Madrid (difusión en talleres) |
| **Presupuesto orientativo** | 15.000 – 35.000 € (contrato menor / convenio) |
