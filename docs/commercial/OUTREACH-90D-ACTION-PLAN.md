2. Día 7 — reenvío + oferta one-pager PDF.

4. Día 21 — archivar o “nurture” (alerta de licitación / news).

## Cómo encontrar el nombre (sin contactos previos)

1. Web del programa (Escuela de Pacientes / Paciente Activo) → “contacto”, “equipo”, “coordinación”.  
2. LinkedIn: `educación diabetológica` + CCAA; `enfermera gestora casos diabetes` + ciudad.  
3. Asociaciones: formulario web + teléfono de sede.  
4. PLACE / portal CCAA: no para primer email; para **alertas** y saber quién compra.  
5. Intro cálida: cada aliado de la vía A debe acabar con “¿a quién en el servicio de salud debería escribir?”.

**No empieces por contratación.** Empieza por **educación diabetológica / enfermería AP / escuela de pacientes**.

## Oferta de piloto (lo que pides)

**Propuesta estándar (copiar a email tras interés):**

- Duración: **6 meses**  
- Alcance: **2–5 centros de AP** o un programa de escuela de pacientes  
- Usuarios: pacientes derivados por educador / enfermería  
- Métricas: altas, niveles completados, exámenes superados (agregadas, sin PHI en informes)  
- Precio orientativo piloto: ver [B2G-ONEPAGER-CCAA.md](./B2G-ONEPAGER-CCAA.md) (15–35 k€ Madrid / adaptar)  
- Fuera de alcance fase 1: integración HCE, app nativa, promesas de HbA1c
